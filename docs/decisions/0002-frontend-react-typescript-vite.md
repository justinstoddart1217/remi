# ADR-0002: Frontend is React 19 + TypeScript on Vite

- Status: Accepted
- Date: 2026-09-24
- Plan: binding decision 2

## Context
The prototype renders React 18 components compiled at runtime by `support.js`. Production needs
a typed, bundled app that looks and moves exactly like the design.

## Decision
- Vite 7, React 19.2, TypeScript 5.9 in strict mode (`noUncheckedIndexedAccess`,
  `noImplicitOverride`, `verbatimModuleSyntax`, `erasableSyntaxOnly`, unused checks).
- react-router 7 (data mode), TanStack Query 5, Zustand 5, `openapi-fetch` over a client
  generated by `openapi-typescript` from `contracts/openapi.json`. KaTeX is lazy-loaded.
- Tests: Vitest with jsdom, Testing Library and msw; Playwright for parity and behaviour.
  Vitest 4 and jsdom 29 are used because their newest majors exclude Node 25 in `engines`.
- Styling: CSS Modules carrying the design's exact px values. `src/styles/tokens.css` is the
  prototype's `:root` block copied verbatim, except that `--pc-accent` / `--fi-accent` default to
  `#526e2a` / `#47619c`: the prototype's `applyTweaks()` always writes those hex values over the
  oklch ones, so they are what the design actually renders. A brand swap edits only this file.
- Fonts are self-hosted (see ADR-0003) under the design's family names, so tokens stay verbatim.

## Consequences
- The dev server binds 127.0.0.1:5173 and proxies `/api` and `/charts` to 127.0.0.1:8765.
- Hand-written `fetch` calls are not allowed; everything goes through the generated client.
